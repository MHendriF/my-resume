## 📌 Ringkasan Eksekutif (Executive Summary)
* **Perusahaan / Klien:** PT Lapantiga Solusi Algoritma
* **Peran:** Android Developer
* **Tipe Sistem:** Native Android Mobile Application (E-Commerce & Personalized Gifts)

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Memberikan pengalaman belanja mobile yang intuitif bagi pelanggan Miracle Wish untuk memilih produk kado kustom, menyematkan pesan ucapan personal, dan melacak pengiriman paket secara real-time.

## 💡 Solusi & Nilai Bisnis (Solution & Business Value)
Mengembangkan aplikasi native Android (`miracle.wish.android`) dengan Material Design, RecyclerView kustom, CardView, AppUpdater untuk pembaruan instan, dan integrasi RESTful API backend.

---

## 🛠️ Tech Stack & Arsitektur Lengkap
* **Bahasa & Platform:** Java / Kotlin Native Android
* **UI Components:** Android Support v7, RecyclerView, CardView, Design Support Library
* **Utility & Core:** AppUpdater v2.7, Multidex v1.0.3, Retrofit / GSON
