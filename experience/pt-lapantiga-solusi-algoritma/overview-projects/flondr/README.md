## 📌 Ringkasan Eksekutif (Executive Summary)
* **Perusahaan / Klien:** PT Lapantiga Solusi Algoritma
* **Peran:** Software Developer
* **Tipe Sistem:** On-Demand Laundry & Vendor Service Marketplace Platform

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Penyedia jasa on-demand membutuhkan platform terpusat untuk memanajemen pesanan penjemputan, penugasan kurir, integrasi notifikasi push status pencucian, dan analitik pendapatan vendor.

## 💡 Solusi & Nilai Bisnis (Solution & Business Value)
Membangun platform marketplace berbasis Laravel 5.3, Vue 2, Firebase Cloud Messaging (FCM), Yajra DataTables, dan ConsoleTVs Charts.

---

## 🛠️ Tech Stack & Arsitektur Lengkap
* **Backend:** Laravel 5.3 MVC, PHP >=5.6.4
* **Frontend:** Vue 2.0, Bootstrap Sass, jQuery
* **Notifications:** Brozot Laravel FCM (Firebase Cloud Messaging)
* **DataTables & Charts:** Yajra DataTables v5.x, ConsoleTVs Charts v5.x
