## 📌 Ringkasan Eksekutif (Executive Summary)
* **Perusahaan / Klien:** PT Lapantiga Solusi Algoritma (Klien: PT Petrokimia Gresik)
* **Peran:** Full Stack Laravel Engineer
* **Tipe Sistem:** Corporate Employee Healthcare Insurance & Claim Management System

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Pengelolaan klaim asuransi kesehatan ribuan karyawan dan keluarga PT Petrokimia Gresik membutuhkan alur verifikasi klaim multi-tahap yang cepat, validasi dokumen medis, serta integrasi wilayah domisili se-Indonesia.

## 💡 Solusi & Nilai Bisnis (Solution & Business Value)
Membangun platform enterprise modern menggunakan **Laravel 10.x**, **Livewire 2.x**, **Vite**, **Tailwind CSS**, **Flowbite**, **AWS S3 Storage (Flysystem v3)**, dan **IndoRegion** untuk mempercepat pemrosesan klaim dan integrasi data faskes.

---

## 🛠️ Tech Stack & Arsitektur Lengkap

### 📦 Versi Framework & Runtime Utama (Core Technology Versions)
| Komponen / Framework | Versi Standar | Keterangan & Peran Arsitektural |
| :--- | :--- | :--- |
| **Backend Framework** | `Laravel v10.x` | Modern Full-Stack PHP Enterprise Framework |
| **Reactive UI Engine** | `Livewire v2.x` | Real-Time Dynamic Form Interactions without full reload |
| **Asset Bundler** | `Vite v4.x` | Ultra-Fast Hot Module Replacement & Build Engine |
| **Styling & UI** | `Tailwind CSS v3.x + Flowbite` | Enterprise Corporate Theme & Modal Components |
| **Cloud Storage** | `Flysystem AWS S3 v3.x` | Encrypted Medical Receipt & Diagnosis Vault |
| **Regional Hierarchy** | `IndoRegion v3.x` | Nationwide Hospital & Health Facility Registry |

---

## 📈 Metrik Dampak Terukur (Google XYZ Formula)
* **Efisiensi Verifikasi Klaim:** Memangkas waktu siklus verifikasi klaim medis karyawan sebesar **60%** melalui alur approval multi-level berbasis Livewire.
* **Keamanan Dokumen Medis:** Seluruh kuitansi rumah sakit dan diagnosa medis tersimpan terenkripsi di AWS S3 sesuai standar privasi data kesehatan.

## 💬 STAR Story untuk Wawancara Kerja (Interview Cheat Sheet)
* **Situation:** PT Petrokimia Gresik memerlukan sistem digitalisasi klaim asuransi kesehatan karyawan dengan validasi dinamis.
* **Task:** Mengembangkan sistem full-stack dengan antarmuka interaktif dan integrasi penyimpanan cloud yang aman.
* **Action:** Menggunakan Laravel 10.x dan Livewire untuk menciptakan pengalaman Single Page Application yang responsif, terintegrasi dengan S3 dan validasi bertingkat.
* **Result:** Proses pengajuan klaim menjadi transparan dan dapat dipantau langsung oleh karyawan secara real-time.
