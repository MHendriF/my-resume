# Virtual Event Platforms & Enterprise CMS Solutions

## 📌 Ringkasan Eksekutif
* **Perusahaan:** PT Lapantiga Solusi Algoritma
* **Peran:** Software Engineer (Part-time / Project-based)
* **Periode:** Jan 2019 – Feb 2024
* **Tipe Aplikasi:** High-Traffic Virtual Event Platforms, Interactive Streaming Portals, Custom CMS & Android Event Apps

---

## 🎯 Masalah & Tujuan Proyek
Selama masa transformasi digital dan event virtual, berbagai korporat membutuhkan platform event online terintegrasi (live streaming, interactive polling, virtual booth exhibition, ticketing) yang dapat menampung ribuan peserta bersamaan dengan latensi rendah.

---

## 🛠️ Tech Stack & Arsitektur
| Komponen | Teknologi | Keterangan |
| :--- | :--- | :--- |
| **Backend & APIs** | PHP (Laravel), Node.js, Express | Event scheduler, live participant state tracking |
| **Databases** | MySQL, MongoDB | Polyglot persistence (Relational ticketing + NoSQL event logs) |
| **Frontend Web** | Vanilla JS, Bootstrap, SASS/SCSS, React | Interactive responsive virtual expo booths |
| **Mobile Apps** | Android Studio, Kotlin, Java, Firebase | Event companion app (QR check-in & schedules) |
| **Dokumentasi & QA** | Swagger / OpenAPI, Postman, Markdown | Comprehensive technical documentation & user guides |

---

## 🚀 Fitur-Fitur Kunci yang Dibangun
1. **Interactive Virtual Expo & Streaming Portal:**
   * Modul panggung virtual interaktif dengan live chat, polling peserta real-time, dan eksibisi booth 2D/3D.
2. **Offline-Resilient Mobile Check-In:**
   * Fitur pemindaian tiket QR code berbasis Android yang tetap bekerja lancar meskipun koneksi venue event tidak stabil melalui local database syncing.
3. **Enterprise Code Documentation & Onboarding Guides:**
   * Pembuatan dokumentasi API interaktif dan arsitektur sistem yang komprehensif.

---

## 📈 Dampak Bisnis & Metrik Pencapaian
* **40% Faster Developer Onboarding:** Standarisasi dokumentasi teknis dan panduan API berhasil memangkas waktu orientasi engineer baru dari 2 minggu menjadi 3-4 hari.
* **Peak Event Concurrency:** Berhasil menyelenggarakan event virtual berskala ribuan peserta tanpa insiden server overload.
