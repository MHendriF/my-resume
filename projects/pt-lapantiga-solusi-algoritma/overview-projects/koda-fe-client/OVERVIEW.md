# NTMC Client App — Command & Control Center Portal

## 📌 Ringkasan Eksekutif & Identitas Proyek
- **Perusahaan / Organisasi:** PT Lapantiga Solusi Algoritma / Korlantas Polri
- **Peran & Tanggung Jawab:** Frontend Engineer
- **Tipe Sistem:** Client-facing Traffic Monitoring Portal

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Menyediakan antarmuka monitoring ringkas bagi operator lapangan dan publik untuk memantau titik lalu lintas dan CCTV daerah.

## 💡 Solusi & Nilai Bisnis (Solution & Business Value)
Membangun portal client berbasis React 19 dan React Router v7 dengan optimasi performa tinggi untuk akses low-bandwidth.

---

## 🛠️ Tech Stack & Arsitektur Lengkap
| Layer / Domain | Teknologi / Library | Keterangan Arsitektural |
| :--- | :--- | :--- |
| **Core** | `React 19, React Router v7, TypeScript 5.9` | Implementasi arsitektural |
| **Design System** | `Tailwind CSS v4, shadcn/ui, Geist Font` | Implementasi arsitektural |
| **Data** | `TanStack Query, Axios` | Implementasi arsitektural |

---

## 🚀 Fitur-Fitur Kunci & Rekayasa Teknis
- Live traffic map & CCTV channel viewer.
- Regional filter per provinsi dan kota.
- High-contrast operational dark mode.
