# Resume Bullets & Action Verbs: NTMC Dashboard Utama

Gunakan kumpulan bullet point berikut untuk Resume, LinkedIn, atau saat menjawab pertanyaan wawancara (*STAR Method*):

### 🌟 Pilihan Bullet Point Utama (Frontend / Full Stack):
* *Developed the NTMC Dashboard Utama, a mission-critical operational and traffic monitoring web application leveraging React 19, React Router v7, TypeScript, Tailwind CSS v4, and shadcn/ui.*
* *Integrated real-time WebSocket communication using Pusher JS for live incident streaming, instant operational alerts, and dynamic dashboard event updates.*
* *Architected high-performance server-side data tables with TanStack Table v8 and server state caching via TanStack Query v5, supporting complex multi-field filtering, sorting, and pagination across large datasets.*
* *Engineered robust type-safe forms with React Hook Form and Zod schema validation, along with interactive data analytics charts using Recharts.*

---

### 💬 STAR Story untuk Wawancara:
* **Situation:** NTMC Polri membutuhkan dashboard baru yang cepat untuk menggantikan sistem lama (Nuxt) agar ribuan operator lalu lintas dapat memantau ribuan CCTV dan menerima insiden real-time.
* **Task:** Memimpin re-arsitektur frontend dari awal menggunakan stack modern React 19 dan React Router v7.
* **Action:** Membangun design system berbasis Tailwind v4 dan shadcn/ui, mengintegrasikan Pusher WebSockets untuk alert instan, dan membuat reusable server-side data table berbasis TanStack Table v8.
* **Result:** Dashboard berhasil dirilis dengan kecepatan rendering instan, integrasi WebSocket sub-detik, dan kemudahan penambahan modul fitur bagi tim developer lain.
