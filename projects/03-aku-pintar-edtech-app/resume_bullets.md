# Resume Bullets & Action Verbs: Aku Pintar Android Platform

* *Spearheaded native Android development for a flagship education platform with 1.5M+ active users and a 4.42/5.00 Play Store rating.*
* *Architected and refactored the app into a modular MVVM structure using Android Jetpack, reducing the application size by 38.6% (from 69.5 MB to 42.7 MB) and boosting runtime performance.*

---

### 💬 STAR Story untuk Wawancara:
* **Situation:** Aplikasi Aku Pintar memiliki ukuran download terlalu besar (69.5 MB), menyebabkan pengguna siswa di luar kota besar enggan mengunduh aplikasi karena keterbatasan kuota.
* **Task:** Melakukan audit menyeluruh terhadap bundle size, arsitektur, dan memangkas ukuran APK tanpa mengurangi fitur fungsionalitas.
* **Action:** Melakukan modularisasi arsitektur MVVM, mengonversi asset gambar ke WebP vector, menghapus dependency usang, menerapkan ProGuard R8 aggressive shrinking, dan memindahkan data offline ke Room DB.
* **Result:** Ukuran aplikasi turun drastis 38.6% menjadi 42.7 MB, waktu startup aplikasi lebih cepat, dan crash-free rate konsisten di atas 99.42% untuk 1.5 juta pengguna.
