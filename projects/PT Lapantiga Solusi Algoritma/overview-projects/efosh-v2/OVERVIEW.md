# Efosh v2 — Virtual Event & Interactive Expo Platform

## 📌 Ringkasan Eksekutif & Identitas Proyek
- **Perusahaan / Organisasi:** PT Lapantiga Solusi Algoritma
- **Peran & Tanggung Jawab:** Software Engineer
- **Tipe Sistem:** Virtual Event & Exhibition Management Platform

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Platform expo virtual membutuhkan sistem registrasi peserta berskala besar, analitik kunjungan booth, dan notifikasi push event.

## 💡 Solusi & Nilai Bisnis (Solution & Business Value)
Mengembangkan platform backend Laravel teroptimasi dengan integrasi Firebase FCM, visualisasi analitik Chart.js, dan pemrosesan gambar terkompresi.

---

## 🛠️ Tech Stack & Arsitektur Lengkap
| Layer / Domain | Teknologi / Library | Keterangan Arsitektural |
| :--- | :--- | :--- |
| **Backend** | `Laravel, PHP, MySQL` | Implementasi arsitektural |
| **Notifications** | `Code-LTS Laravel FCM` | Implementasi arsitektural |
| **Analytics & Charts** | `ConsoleTVs Charts, Chart.js` | Implementasi arsitektural |
| **Image Processing** | `Intervention Image, DomPDF` | Implementasi arsitektural |

---

## 🚀 Fitur-Fitur Kunci & Rekayasa Teknis
- Registrasi peserta event dengan verifikasi email/SMS.
- Analitik kunjungan booth pameran virtual dan interaksi peserta.
- Broadcasting notifikasi jadwal panggung via Firebase FCM.
