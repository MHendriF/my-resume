## ➕ Cara Menambahkan Dokumentasi Proyek Baru

Untuk menambahkan folder perusahaan / proyek baru:
1. Salin template dari folder [`template-project/`](./template-project/).
2. Buat folder baru sesuai nama perusahaan atau proyek.
3. Isi file `overview.md` dan `resume_bullets.md` di dalamnya.
